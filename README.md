# Model-Choice-Matters-More-Than-Prompts-Evaluating-LLM-Story-Judges-Across-Techniques-and-families
Model Choice Matters More Than Prompts evaluates LLMs as story judges using the HANNA benchmark. We compare GPT-4.1 Mini and Claude variants across five prompting strategies and six narrative dimensions, showing that model selection impacts human alignment more than prompt engineering.
